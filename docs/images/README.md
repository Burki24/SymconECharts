# Dokumentationsbilder

Die JPEG-Aufnahmen vom 03.11.2026 stammen aus der per MCP verbundenen
Testinstallation. Sie zeigen vorhandene, bereits übernommene JSLive-Testmodelle
in der nativen ECharts-HTML-Kachelausgabe, gerendert durch die MCP-Kachelvorschau.
Instanzen, Quellen, Archive und Designs wurden für die Bilder nicht geändert.

| Datei | Inhalt |
| --- | --- |
| [jslive-import-gallery.jpg](jslive-import-gallery.jpg) | Sechs Ziele: Gauge, Pie, bewegter Verlauf, historisches Radar, Linien-/Balkenmischmodell und eigene SVG-Form. |
| [jslive-svg-and-history.jpg](jslive-svg-and-history.jpg) | SVG-Fortschritt und historisches Mischmodell nebeneinander; beide sind ECharts-Ziele. |

Die Bildausschnitte enthalten keine Browseradresszeile, Zugangslinks,
Installations- oder Objektkennungen. Sichtbar sind synthetische Testbezeichnungen.
Die Bilder wurden vor der Einbindung angesehen. Sie dokumentieren eine
Darstellung, keinen erneuten Live-Abnahmelauf oder einen IPSView-Screenshot.
Die MCP-Vorschau zeigt den initialen Zustand; nachträglich gepushte Werte sind
darin nicht live. Ein bewegter Verlauf erscheint als einzelne Animationsphase.

Ein Vorher-/Nachher-Vergleich des Originals wird durch diese Bilder nicht
behauptet. Die bereits bestätigte funktionale Kachel-/IPSView-Abnahme bleibt
ein eigener Nachweis.
